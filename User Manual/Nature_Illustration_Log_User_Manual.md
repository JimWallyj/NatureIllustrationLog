# Manual
## Nature Illustration Log and Locator

### 1. Getting Started
**Purpose / problem statement:** The Nature Illustration Log and Locator app provides a simple tool for nature illustrators to capture a source photo and basic details in the field on their device. The resulting repository should prove useful to the nature illustrator for their next illustration project. The illustrator user will import their nature subject from the Photos app. The file entries in this Nature Illustration Log & Locator app will include one or more photos of the subject (with dates taken), user field notes, initial notes and plans that support the user's illustration project, and later, photos of the resulting illustration. The illustration project is not part of this app. The app merely stores a picture of the nature subject and related user notes.

Sharing via eMail from Mac to iPhone = Mac requires user to open a draft email first before sharing by email from the app. The app is then added to the email draft. iPhone auto-opens the email draft and adds the file attachment. Receiving on the iPhone: email includes a download icon or one can double click the icon to save it. Mac: Double clicking file icon in eMail on receiving Mac requests app name then the file opens in our app.  It also has a download icon in the Mac email. Sharing via Messages = Mac requires a save to Downloads by right-clicking icon in Messages.  Normal clicking icon in Mac Messages doesn't open the file in app.  Messages on iPhone requires a hold down on the icon in Messages which brings up the  download icon. Normal clicking the icon in Messages on iPhone provides the option to download to the iPhone Files folder.  Once in the Mac or iPhone folders the files can be imported from the app.  Sharing via AirDrop = iPhone to Mac works well. Once transferred from the iPhone the Mac opens the Downloads File folder with the AirDropped file contained within.  Mac to iPhone doesn't seem to work.
